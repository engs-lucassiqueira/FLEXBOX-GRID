O que é Flexbox?

Flexbox é um modelo de layout do CSS que ajuda a organizar e alinhar elementos dentro de um contêiner. Ele é unidimensional: trabalha principalmente em uma direção por vez, em linha ou em coluna.

Para começar, aplique display: flex; ao elemento que contém os itens. Esse elemento vira o contêiner flexível; seus filhos diretos viram os itens flexíveis.

.container {
  display: flex;
}

Eixo principal e eixo transversal

O Flexbox organiza os itens ao longo de dois eixos. O eixo principal acompanha a direção definida por flex-direction. O eixo transversal cruza o eixo principal.

Por padrão, a direção é uma linha, da esquerda para a direita. Com flex-direction: column;, os itens ficam em coluna.

.container {
  display: flex;
  flex-direction: column;
}

Alinhamento e espaçamento

justify-content distribui os itens no eixo principal. Já align-items alinha os itens no eixo transversal.

  • justify-content: center; centraliza no eixo principal;
  • justify-content: space-between; distribui o espaço entre os itens;
  • align-items: center; centraliza no eixo transversal;
  • gap define o espaço entre os itens.
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Para centralizar um item nos dois eixos, combine justify-content: center; e align-items: center;.

Quebra de linha e tamanho dos itens

Por padrão, os itens tentam ficar em uma única linha. Com flex-wrap: wrap;, eles podem passar para a linha seguinte quando não houver espaço suficiente.

A propriedade flex permite que um item cresça para ocupar o espaço disponível. Por exemplo, flex: 1; faz com que os itens dividam esse espaço.

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.item {
  flex: 1;
}

Quando usar Flexbox?

Use Flexbox quando precisar alinhar ou distribuir elementos em uma direção, como em menus, grupos de botões, cabeçalhos e cartões em uma linha. Para layouts que precisam controlar linhas e colunas ao mesmo tempo, o CSS Grid pode ser mais adequado.
