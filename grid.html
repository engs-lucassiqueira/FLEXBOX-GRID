O que é CSS Grid?

CSS Grid é um sistema de layout que organiza elementos em linhas e colunas. Ele é útil quando queremos controlar as duas direções ao mesmo tempo, como em uma grade de cartões ou no layout de uma página.

Para começar, aplique display: grid; ao contêiner dos elementos. Os filhos diretos desse contêiner passam a ocupar células da grade.

.container {
  display: grid;
}

Definindo colunas e linhas

A propriedade grid-template-columns define quantas colunas existem e a largura de cada uma. Cada valor cria uma coluna. A propriedade grid-template-rows permite definir as alturas das linhas.

A unidade fr divide o espaço disponível em partes. Por exemplo, 1fr 1fr 1fr cria três colunas iguais.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 80px 80px;
}

Espaço entre as células

Use gap para definir o espaço entre as linhas e as colunas. Também é possível separar os valores: column-gap controla o espaço entre colunas e row-gap controla o espaço entre linhas.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

repeat(3, 1fr) é uma forma curta de escrever três colunas iguais.

Ocupar mais de uma coluna ou linha

Um item pode ocupar várias células usando grid-column ou grid-row. Por exemplo, grid-column: span 2; faz o item ocupar duas colunas.

.destaque {
  grid-column: span 2;
}

Quando usar Grid?

Use Grid quando precisar montar uma estrutura com linhas e colunas, como galerias, listas de cartões e divisões principais de uma página. Para organizar itens em uma única direção, Flexbox pode ser mais simples.
